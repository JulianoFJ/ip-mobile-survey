# 0005: CRS de armazenamento e de processamento

- **Status:** aceita
- **Data:** 2026-11-19

## Contexto
Erro de CRS/unidade é silencioso e catastrófico (§19, item 3).

## Decisão
- Armazenamento: **SIRGAS 2000 geográfico (EPSG:4674)**.
- Processamento: **UTM SIRGAS 2000 do município** (BH: EPSG:31983).
- Toda coordenada projetada carrega o CRS (`ProjectedPoint.crs`); operações entre CRS diferentes levantam `CRSMismatchError`.
- Alturas elipsoidais na trajetória; ortométricas só na exportação.

## Consequências
Testes de ida e volta obrigatórios para toda transformação.
